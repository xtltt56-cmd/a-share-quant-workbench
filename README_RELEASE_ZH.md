# 股票量化研究工作台 Windows 版

## 下载选择

- `Online.zip`：推荐。包体较小，首次安装会从 NuGet 获取官方 CPython 包，并从 PyPI 安装受约束的依赖。
- `Portable.zip`：已包含 Python 和运行依赖，解压后即可启动，适合网络受限环境，但文件较大。

## 使用步骤

1. 在 GitHub Releases 下载最新版本，并核对同一页面的 `SHA256SUMS.txt`。
2. 把 ZIP **完整解压**到 D 盘或其他数据盘。不要直接在压缩包预览窗口中运行。
3. 在线版双击 `安装股票量化研究工作台.cmd`；便携版双击 `启动股票量化研究工作台.cmd`。
4. 安装或启动成功后会打开“投资总览”和“本地人工投顾”两个浏览器页面。
5. 关闭系统时双击 `停止股票量化研究工作台.cmd`，或使用页面中的安全退出。

程序、行情、模型、缓存和日志默认全部留在解压目录内。若放在系统盘，安装器会明确警告并要求确认。不要把他人的 `.env`、持仓、成交、`.runtime`、`data` 或模型目录复制到自己的安装中。

## 搜索股票与自选

在顶部选择「搜索股票」，按代码或中文简称查找沪深北 A 股。第一次使用需联网取得证券名录，之后可离线搜索本地快照。点击「加入自选」后，从「我的自选」查看收藏。旧浏览器收藏首次打开新版时会迁入本机。

股票详情可查看已有日 K 线。缺少所选范围的历史时，联网点击「补齐日线」。这项下载只处理当前股票，并使用独立图表缓存。自选报价显示采集或交易所时间，有行情时效问题时会显示对应状态。

更新或回退前将 `.runtime/watchlist/favorites.json` 留作自选备份。源码中的独立在线页需用 `scripts/build_online_watchlist.py` 和本机有效证券名录构建，部署构建产物后才可在线使用，收藏保存在当前浏览器。

## 港股和美股研究

通过左上角市场选择器切换市场，进入「日选研究」刷新日线。当前海外市场覆盖预设研究样本。默认日线来自新浪财经，港股每手股数和适用印花税标记来自港交所公开名录。美股可选在本机 `.env` 配置 `APCA_API_KEY_ID` 和 `APCA_API_SECRET_KEY`，在对应数据权限下获取 Alpaca SIP 历史日线和 IEX 单交易所成交。

切换市场后，可在「搜索股票」中更新证券名录并按代码或名称查找。港股名录支持繁简体名称搜索。名录外的行情可用性取决于数据源，个股详情会显示日线日期和更新状态。

自选与本地人工账本分市场保存。账本按当地交易日登记已完成的买卖和实付费用，支持本币入金、估算交收日和待结算卖出款。更新前可单独备份 `.runtime/foreign-markets/US/` 和 `.runtime/foreign-markets/HK/` 中的 `favorites.json`、`ledger.json` 与 `catalog.json`，其中名录保存了自选、账本所引用的证券标识。建议以实际券商结单核对本地记录。

## AI 分析（可选）

发布包已包含 Agent 所需的 SDK，但默认仍使用标准工作流，不自动下载本地模型或调用收费 API。
打开左侧「AI 分析 → 配置与 API」，选择云端模式并输入自己的 DeepSeek API 密钥；密钥仅在本机通过 Windows 当前用户加密保护保存，不包含在发布包中。
完成费用及生成授权、连接核验后，批量选择股票并点击「开始分析已选股票」。联网信息、工作流事实、Agent 推断及缺失条件分别展示，不自动下单。
详细步骤见仓库的 [分析助手说明](https://github.com/xtltt56-cmd/a-share-quant-workbench/blob/main/docs/AGENT_QUICKSTART_ZH.md)。

## 数据与投资边界

AKShare 和 BaoStock 默认不需要 Token，但公开数据源可能延迟、中断或调整接口。数据过期或校验失败时，系统会停止生成新的有效指导。Tushare、RQData 和财信 QMT 都属于可选连接，必须使用用户自己的授权。

本软件仅用于量化研究、纸面监控和人工决策辅助，不承诺收益，不代替持牌投资顾问，不会自动向券商提交真实委托。任何真实交易均由用户独立判断并手工完成。

## 更新

先备份账户账本、导入快照、日选与价格计划、前瞻账本、研究检查点及 Agent 费用账本。关闭旧版后再启动新版。回退前先保全升级后新增的账户、前瞻和费用记录，再核对要恢复的文件。

在线安装使用经摘要核验的 CPython NuGet 包，在工作台目录内解包。

始终从以下固定地址获取最新版：

https://github.com/xtltt56-cmd/a-share-quant-workbench/releases/latest

不要覆盖旧目录中的 `.runtime`、`data` 和 `.env`。正式升级工具完成前，建议先完整保留旧目录，再把需要的账户导出文件重新导入新版。
