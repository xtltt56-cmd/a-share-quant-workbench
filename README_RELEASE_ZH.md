# A股量化交易系统 Windows 版

## 下载选择

- `Online.zip`：推荐。包体较小，首次安装会从 Python 官方网站和 PyPI 下载经过约束的运行依赖。
- `Portable.zip`：已包含 Python 和运行依赖，解压后即可启动，适合网络受限环境，但文件较大。

## 使用步骤

1. 在 GitHub Releases 下载最新版本，并核对同一页面的 `SHA256SUMS.txt`。
2. 把 ZIP **完整解压**到 D 盘或其他数据盘。不要直接在压缩包预览窗口中运行。
3. 在线版双击 `安装A股量化交易系统.cmd`；便携版双击 `启动A股量化交易系统.cmd`。
4. 安装或启动成功后会打开“投资总览”和“本地人工投顾”两个浏览器页面。
5. 关闭系统时双击 `停止A股量化交易系统.cmd`，或使用页面中的安全退出。

程序、行情、模型、缓存和日志默认全部留在解压目录内。若放在系统盘，安装器会明确警告并要求确认。不要把他人的 `.env`、持仓、成交、`.runtime`、`data` 或模型目录复制到自己的安装中。

## 数据与投资边界

AKShare 和 BaoStock 默认不需要 Token，但公开数据源可能延迟、中断或调整接口。数据过期或校验失败时，系统会停止生成新的有效指导。Tushare、RQData 和财信 QMT 都属于可选连接，必须使用用户自己的授权。

本软件仅用于量化研究、纸面监控和人工决策辅助，不承诺收益，不代替持牌投资顾问，不会自动向券商提交真实委托。任何真实交易均由用户独立判断并手工完成。
