# 前端升级交接记录 · 2026-09-13

## 使用入口

- 桌面原“A股量化交易系统”快捷方式继续使用。
- `/` 默认投资总览；`/advisory` 默认我的持仓，同一套导航可切换六个页面。
- `/#daily` 日选研究；`/#monitor` 盘中监控；`/#models` 模型观察；`/#system` 数据与系统。
- 兼容界面保留在 `/classic` 和 `/classic/advisory`。
- 顶部支持深浅主题、紧凑模式；左侧支持折叠导航。

## 本次实现

前端文件独立放在 `src/a_share_quant/workbench/static/`，随 Python 包一同安装，不需要 Node 开发服务器，不依赖远程 CDN 运行。ECharts 固定为 5.6.0，官方压缩构建及 LICENSE/NOTICE 随项目保存。

总览展示日选、监控、自选、数据质量和真实待处理事项。日选支持名称/代码搜索、排序及区间筛选；监控支持全部、日选、持仓、自选四种范围。点击股票打开详情抽屉，显示本地日K线、成交量、MA20/MA60、价格区间、指导限制、候选原因和来源版本。MA 仅按所选历史窗口计算，窗口开头不足均线周期时保留缺失。

持仓分本机账本和券商快照独立展示。成本分布按数量乘平均成本，不冒充实时仓位或净值。成交登记预览内部管理令牌，修改表单后废弃预览；导入使用中文表格、接受/拒绝行数和逐行错误。预览与确认继续调用原有受保护的后端接口。

模型页展示实际冠军、治理事件数与模型记录状态。当前治理接口没有提供挑战者成绩/成熟样本明细，因此该页明确说明未提供，不生成成绩图或假百分比。分时图、完整账户净值、新闻及行业热力图仍需要对应数据，未加入本版。

新增 `GET /api/stocks/history?symbol=600036&limit=120`：只读配置的数据根目录，限制六位代码与 60/120/252/600 条范围，拒绝路径穿越、符号链接，不联网下载，不写数据。缺失文件返回空数据和中文说明。

新增 `POST /api/system/quit`：要求 `X-Quant-Workbench-Request: safe-exit`，触发服务退出，已有 run_server 清理流程负责停止后台行情、收盘任务和研究任务。原 `/api/system/safe-exit` 保持原语义。

代码指纹包含 HTML/CSS/JS，以便桌面启动器识别页面更新。前端偏好与自选只写浏览器本地存储；没有将账户凭据写入浏览器存储。

## 验证与限制

已执行新前端、原工作台、服务生命周期、桌面启动器、账户导入 HTTP、人工投顾相关 61 项测试并全部通过，其中包括新增退出路由和前端资源变更触发重启的定向验证。浏览器验证使用离线服务和现有真实本地日选/日线；不会为验收登记虚构成交。公开实时行情的可靠性属于原有数据链路限制，本次视觉升级不改变其事实状态。

浏览器重点检查搜索、详情图表、中文提示、主题切换、窄屏局部滚动、预览输入失效及错误状态。详情显示后台时间和指导有效日期；非良好行情不添加价格定位标记。
