# 财信导出文件导入操作手册

本功能只读取你从财信证券客户端使用官方功能导出的文件，不登录、控制或逆向客户端，也不会提交委托。它的作用是减少重复手工登记，并把“券商持仓快照”和“本机成交账本”分开保存。

## 第一次准备

1. 双击桌面的“A股量化交易系统”快捷方式。
2. 系统会自动打开“官方日选 + 盘中监控”和“本地人工投顾”两个页面。
3. 在财信证券专业版中登录你的账户。

## 导出持仓样例

1. 进入底部“持仓”页面。
2. 在持仓表格区域点击右键，选择“导出”“导出数据”或“保存为”。不同客户端版本的文字可能不同。
3. 优先选择 CSV、XLSX；财信/同花顺部分版本会把制表符文本保存为 `.xls`，系统也支持这种格式。
4. 常见的有效字段包括：证券代码、证券名称、股票余额、可用余额/可用数量、冻结数量、成本价、可用资金、日期。
5. 将文件保存或复制到：

   `D:\量化交易\.runtime\advisory\import-inbox`

## 导出成交样例

1. 进入“当日成交”“历史成交”或“成交查询”。
2. 设置需要导出的日期范围。
3. 点击右键或工具栏中的“导出/保存”。
4. 常见的有效字段包括：证券代码、证券名称、成交数量、成交价格、买卖标志、成交日期。
5. 将文件放入同一个收件箱目录。

## 导入页面操作

1. 打开“本地人工投顾”页面。
2. 在“券商导出文件导入”区域点击“扫描导出文件”。
3. 选择文件后点击“生成预览”。
4. 核对证券代码、名称、数量、价格、日期和拒绝行。
5. 确认无误后点击“确认导入”。

成交文件会进入本机追加式成交账本；持仓文件会进入独立的券商导入快照。重复确认同一成交文件不会重复记账；文件在预览后被修改，确认会失败并要求重新预览。

## 隐私与安全

导出前可以删除姓名、资金账号、股东账号、银行卡号等无关列。系统只保存白名单字段、文件摘要和导入时间，不保存未映射的原始列。不要把账号、密码、验证码或交易令牌发送给任何人。

## 无法识别文件时

系统会显示“已发现列名”和缺失的语义字段，但不会猜测列含义。请保留原始文件，并提供一份删除姓名、账号、股东号等敏感信息后的表头和一两行样例；开发时只增加明确列名映射和回归测试，不使用 OCR、抓包或客户端逆向。

## 口径限制

- 持仓快照不是历史成交，不会自动改变本机账本现金。
- 本机账本是已确认的人工成交或成交明细导入；券商快照是独立来源。
- 系统仍然要求人工执行交易，不包含下单或撤单能力。
- 页面推荐和风险提示不能保证收益或预测准确，券商正式成交与结算记录优先。
