## 边界与限制

1. 一致性复核不能证明免费供应商永远不会延迟、限流、停服或修订数据。
2. 日线真实性不能证明推荐会盈利；候选分数是固定因子横截面排名，不是校准后的收益概率。
3. 盘中价格只有在数据质量和新鲜度门槛通过时才能视为当前观察值。
4. 公开仓库不包含本机行情和账户数据。克隆者必须自行运行数据更新流程，页面才会产生其本地候选。
5. 系统不包含自动实盘执行，任何买卖均应由使用者在券商端人工确认。
