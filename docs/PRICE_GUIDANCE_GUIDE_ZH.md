# 价格指导与模型治理操作指南

## 页面和边界

双击桌面“ A股量化交易系统 ”快捷方式后，工作台会在本机打开两个页面：

- `http://127.0.0.1:8765/`：官方日线候选与盘中监控；
- `http://127.0.0.1:8765/advisory`：本地人工投顾、持仓保护和模型治理。

系统只做数据整理、纸面分析和本机记录。它不会登录财信证券、不会读取客户端内存、不会提交买卖委托。真正买入或卖出必须由用户在券商客户端人工完成。

## 官方日选和价格字段

官方日选使用已保存的日线数据生成固定版本的候选排序。候选页中的“参考买入区间”是保守的研究参考，“最高可接受价”是价格约束，“失效价”表示原有假设失效；它们不是保证盈利价，也不是自动止损指令。

盘中监控只叠加最新行情，不重新改写日选边界。行情过期、来源失败、涨跌停或复权信息不完整时，页面显示“暂无可靠指导”，建议数量为 0。

## 持仓保护

在“持仓与状态”中可以看到本机人工成交记录和券商导入快照。两者保持独立口径，不会把导入持仓伪造成历史成交。持仓指导包含保护价、减仓区间、可卖数量和 T+1 约束；没有经过核验的当前价时不会用成本价冒充行情。

## 研究数量为什么可能为 0

研究级挑战者使用成本后的超额收益标签、走步样本外验证、概率校准和共形区间。样本不足时概率或区间状态为“未校准”，研究级价格计划强制数量为 0。这样做是为了避免把未验证预测显示成确定性买卖建议。

## 模型治理和人工批准

“模型治理”区域会显示当前冠军、挑战者和影子运行状态。挑战者必须同时满足影子天数、成熟样本数、样本外窗口、多个预测周期、Brier/ECE、成本后表现、回撤、容量、Deflated Sharpe、PBO、市场状态和无泄漏等门槛。

即使所有门槛通过，也只能进入“等待人工批准”。操作流程是“预览 → 一次性确认令牌 → 确认”；报告内容变化会使令牌失效并返回“报告已变化”。批准和回滚都会写入审计记录，不能使用自动批准参数。

## 工作台关闭与数据源

工作台启动时才允许启动受控研究任务；不会创建开机启动或计划任务。关闭时先保存 JSON 检查点，再停止由本工作台登记且命令行匹配的子进程。检查点损坏或命令不在白名单时不会恢复。

免费数据源用于研究和纸面监控，不等同于实时交易级行情。接入财信 QMT 仍需要财信开通只读 XtQuant 权限并由用户在本机安装、登录 QMT；普通财信客户端登录不能替代该权限。
