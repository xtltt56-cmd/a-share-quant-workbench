# AI 分析使用说明（v0.2.4）

AI 分析是可选的只读研究层。标准工作流继续负责日选、监控、持仓与价格计划；Agent 不修改正式分数、指导价或交易数量，不执行委托，不发送私人持仓。

## 连接云端模型

1. 完整解压并启动最新 Windows 发布包，打开工作台左侧「AI 分析」。
2. 点击「配置与 API」，或进入「数据与系统」中的分析助手设置。
3. 选择云端模式。当前对接 DeepSeek 官方接口，实际模型 ID 为 `deepseek-flash`，不是 OpenAI 云端服务。
4. 在密码式密钥输入框中填入自己的 DeepSeek API 密钥，点击保存。保存后输入框清空；页面和状态接口不显示完整密钥。
5. 设定并确认每日费用、每任务费用与累计实验费用，再明确勾选收费生成授权。初始 Agent 关闭，保存设置不会自动收费。
6. 点击「核验连接（不生成内容）」。该操作核验官方接口及模型列表，不发送股票研究内容。连接成功不等于余额充足或预测质量合格。
7. 进入 AI 分析页面，确认状态为「可开始分析」。平台重启或更换密钥后需要重新核验连接。

密钥使用 Windows 当前用户 DPAPI 加密保护，保存在安装目录的 `.runtime/agent` 下。该目录不属于源码或发布包，不要分享、提交或搬到他人的账户。原有环境凭据仍受支持；页面保存的本机密钥优先，损坏时停止调用，不静默切换账户。

## 批量研究股票

1. 用股票名称或代码筛选列表，勾选需要分析的股票；也可添加六位证券代码。
2. 支持选择当前筛选结果和清空选择，一批最多十只，逐只执行。
3. 选择「综合研究：联网信息 + 趋势与风险」，按需开启公开网页检索。
4. 点击「开始分析已选股票」后才发送收费生成请求。页面显示执行进度；「停止本批分析」取消当前任务并停止后续股票。
5. 结果分开显示工作流原始事实、Agent 补充判断、证据观察、待验证推断、缺失条件、来源链接和费用估算。

其他预设问题可解释候选入选、指导价条件、数据有效性或工作流异常。个股详情和日选中的 AI 入口可把股票加入分析页面，不会因点击入口自动收费。

## 如何看待结果

- 排序分数不是上涨概率，AI 文字也不是交易指令。
- 数据、公告或价格计划存在阻塞条件时，结果保持限制；没有可靠指导价时不补造买入价。
- 「已完成证据检查」指结构及引用关系通过检查，不表示每句话、原始资料或投资表现都得到独立证明。
- 标题、搜索摘要、正文节选和读取失败分别标注；日期未知不当作最新，公司相关资讯不等于公司事件。
- 原始披露、财报、行业或宏观证据不足时，只能作有条件观察；媒体观点不能替代官方公告。
- 页面结果是生成时的研究快照，不是持续更新的交易信号。刷新不恢复会话结果，不自动重新生成；重新分析需要再次主动点击。
- 免费网页可能包含无关信息、旧闻或无法读取的页面；来源数量不等于独立可靠来源的数量。

## 费用、停止与安全边界

当前试用保护最高为每日 0.10 美元、每任务 0.02 美元、实验累计 3 元人民币，可下调；三道限制任一不足即停止。费用根据 API 返回 Token 用量估算，最终以服务商账单为准。失败、取消或未知用量可能仍收费，因此保留保守预留；累计实验费用不会跨日或重启清零。

计价配置到期后停止云端调用，需维护者核实报价并更新配置。平台不擅自绕过限额、自动重试收费请求或切换到另一个模型账户。

关闭浏览器标签不等于关闭后台。使用「安全退出」或随发布包提供的停止脚本停止系统。应用侧取消不保证服务商立即停止计算或收费。没有开机自启动。

## 本地模式与依赖

可选本地模式使用已安装的 Ollama 和页面指定模型。平台不下载模型、本地失败不自动切换云端，云端失败也不自动切换本地。本地模型的回答质量和运行速度需要单独测试，不能由云端验收代替。

v0.2.4 在线安装流程和便携包包含受约束的 Agent SDK，但不包含模型权重或 API 密钥。源码安装可选择 `agent` 依赖；已有旧运行环境若提示缺少 SDK，可执行项目的 `scripts/install_agent.ps1`，依赖下载和临时文件保留在项目内，不调用收费 API。

标准工作流可独立使用。API 密钥、个人账户文件、本机费用账本、实验报告和缓存均不应上传 GitHub。
