# A股量化系统可靠性升级设计

## 目标与边界

本升级修复审查中已复现的实时行情、日线历史、选股资格、交易日、持仓指导和研究任务持久化问题。系统继续保持“只读行情、人工下单、失败关闭”，不因页面需要展示内容而伪造行情、交易所时间、收益预测或持仓。

## 架构

实时链路把全市场快照作为带交易所时间的权威免费数据，优先股票只从同一份新鲜快照筛选；完整快照采用代际替换，逐股票判断质量，健康接口分离“进程可用”和“数据可用”。外部调用使用受控长生命周期执行器，限制同时存在的工作线程，关闭时等待回收。

日线链路保存明确的复权模式并验证文件完整性。免费首版改用不复权原始价格，历史不足、文件损坏或复权模式变化时进行有界回补；选股在评分前连接点时股票状态，按合格股票覆盖率选择共同截止日。

运行时只保留一个日终协调器。它使用交易日历决定目标日和指导价有效日，原子发布日选与指导价，并把失败原因展示到工作台。持仓指导使用“本地账本与券商导入并集 + 经质量门验证的实时价格”，不把成本价当行情。

研究链路在数据可靠后启用。训练产物、评价报告和冠军版本持久化；任何挑战者只能在滚动样本外、成本后指标和人工批准均通过后替换冠军。训练仅随工作台运行，不设置开机自启动。

## 失败处理

- 没有交易所时间的报价只能显示为降级，不能触发买卖状态。
- 历史不足、损坏、复权模式不一致或股票状态未知时，该股票不得参与正式日选。
- 日终刷新失败时保留上一个已验证版本，同时显示失败时间和原因。
- 缺少可靠当前价时，持仓继续显示“暂无可靠指导”。
- 训练失败不得影响行情、日选或人工账本，也不得自动晋升模型。

## 验收标准

1. 带交易所时间的免费快照连续两次变化后可以达到 `GOOD`；陈旧股票不会污染其他股票。
2. 历史不足或损坏文件不会被误判为刷新完成；复权尺度不能混用。
3. 停牌、ST、退市风险和上市不足阈值的股票不进入正式候选；单只停牌股票不拖回全市场截止日。
4. 周五和节假日前生成的计划指向下一个真实交易日。
5. 导入持仓即使未登记到本地账本，也能在取得可靠行情后生成持仓指导。
6. 工作台运行期间可以执行日终刷新和研究任务，关闭后停止；重启后治理状态可恢复。
7. 全量测试、Ruff、编译、依赖检查和核心运行态烟雾测试通过。
