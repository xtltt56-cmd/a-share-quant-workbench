# 财信导出文件自动导入桥设计

## 目标

在不连接、逆向或控制财信证券客户端的前提下，为本地 A 股量化系统增加一个安全的账户数据入口：行情继续由公开数据源自动获取；用户从券商客户端导出的 CSV/XLSX/XLS 文件放入固定收件箱后，系统自动发现、识别、预览，并在用户确认后更新本地只读账户视图或成交账本。

## 不做的事情

- 不抓包、不读取进程内存、不调用财信私有接口、不模拟登录或点击。
- 不存储券商账号、密码、验证码或交易令牌。
- 不提交、撤销或修改任何证券委托。
- 不把未经确认的文件内容写入账本。
- 不把持仓快照伪造成历史成交，也不把公开行情冒充券商结算数据。

## 架构

采用与 MT5 官方 Python 桥相似的“适配器边界”，但数据入口是券商正式导出文件，而不是未经授权的终端 IPC。`AccountImportInbox` 只扫描启动参数指定目录的直接子文件，拒绝符号链接、目录穿越、超大文件及不支持格式；解析器只保留允许的账户字段。成交明细沿用已有的 `AccountEntryService` 预览和哈希链账本；持仓快照写入独立、带摘要的原子 JSON 快照，避免虚构成交和现金变化。

工作台增加三个本地接口：列出收件箱文件、生成一次性预览、确认预览。浏览器不能传入任意文件路径，只能提交后端生成的文件标识和预览令牌。确认时重新校验文件摘要；文件在预览后发生变化则失败关闭。

## 支持的数据

### 成交明细

必需语义字段为证券代码、成交数量、成交价格；证券名称、买卖方向和成交日期可以从常见中文/英文列名自动识别。缺少方向时仅按买入处理，页面会明确提示。每行生成由文件摘要和行号确定的事件编号，重复确认保持幂等。

### 持仓快照

必需语义字段为证券代码、持仓数量、成本价；证券名称、可用数量、冻结数量、快照日期和可用资金为可选字段。确认后保存为独立的“券商导入快照”，工作台同时展示本机手工账本和券商导入快照，并标明来源、导入时间和文件摘要，不自动合并两套口径。

## 中文界面流程

1. 用户在财信客户端导出成交明细或持仓文件。
2. 文件保存或复制到桌面快捷方式所配置的“券商导入收件箱”。
3. 打开“本地人工投顾”页面，点击“扫描导出文件”。
4. 选择文件并点击“生成预览”。页面显示识别类型、有效行、拒绝行和字段说明。
5. 用户核对后点击“确认导入”。成交明细进入哈希链账本；持仓文件进入独立快照存储。
6. 同一文件重复导入不会重复记账；文件被修改后原预览自动失效。

## 安全与可靠性

- 收件箱在服务启动时解析为绝对路径，只接受直接子文件。
- 文件大小上限 25 MiB；扫描数量设上限，避免目录滥用。
- CSV 支持 UTF-8 BOM、UTF-8 和 GB18030；Excel 由 pandas 的受支持引擎读取。
- 导入预览只存在内存中，服务重启后必须重新预览。
- 持仓快照采用同目录临时文件、`fsync`、原子替换和 SHA-256 完整性校验。
- HTTP 仅绑定 `127.0.0.1`，写请求继续要求本地请求头和 JSON 内容类型。
- 所有界面都保留“仅供人工复核、系统不会提交委托”的提示。

## 验收标准

- 常见财信/同花顺中文列名能够自动识别成交或持仓文件。
- UTF-8、GB18030 CSV 和 XLSX 均有测试覆盖。
- 未确认预览不改变任何持久化状态。
- 文件篡改、重复确认、损坏快照、链接文件和目录外路径均被安全处理。
- 工作台可以扫描、预览、确认并用简体中文显示导入结果。
- 桌面快捷方式启动时自动创建并连接默认收件箱。
- 全量 pytest、Ruff 和差异检查通过，且现有行情、日选、人工登记和永久只读边界不回归。
