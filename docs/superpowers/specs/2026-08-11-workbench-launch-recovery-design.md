# 工作台启动恢复与收盘状态设计

日期：2026-08-11

## 背景与证据

本地工作台曾在 14:26 以 `--offline` 启动。桌面快捷方式随后发现 PID 仍存活，只重新打开浏览器，没有核对运行模式或代码版本，因此同时出现两个现象：盘中监控没有行情，人工投顾页面仍是旧版且缺少“扫描导出文件”。手工重启为 `--network` 后，新版导入页面立即恢复；联网探测可取得 5538 条A股行情，10只日选股票均存在于快照中。

当前诊断时间已超过 15:00。联网进程在收盘后停止请求盘中行情是正确的安全行为，但页面将其表现为离线或失败，容易被误认为网络故障。

## 目标

1. 双击桌面快捷方式时，如果现有工作台的联网模式与本次请求不一致，自动停止旧进程并按请求模式重启。
2. 如果代码版本已经变化，自动停止旧进程并加载当前代码；版本相同且模式一致时继续复用进程，避免重复启动。
3. 非交易时段明确显示“市场已收盘”，不把收盘状态描述成网络离线。
4. 保持现有安全边界：只监听 `127.0.0.1`，不增加自动交易、券商登录、账号密码或远程控制能力。

## 非目标

- 不改变A股交易时段规则。
- 不在收盘后把静态收盘价冒充为连续实时行情。
- 不绕过实时数据质量门；仍要求至少两次不同、完整、时间有效的快照才能显示“良好”。
- 不解决券商 QMT 授权或自动下单问题。

## 方案

### 启动元数据

启动器新增本地运行元数据文件 `.runtime/quant_workbench.launch.json`，只记录：

- 格式版本；
- 工作台 PID；
- 启动模式 `network` 或 `offline`；
- 当前 Git 提交号；
- `src/` 与 `scripts/` 中生产源码的内容指纹；
- 启动时间。

该文件不保存账号、令牌、环境变量或行情内容。写入使用同目录临时文件和替换，避免产生半写文件。

### 复用与重启判定

桌面启动脚本发现 PID 存活后按以下顺序判断：

1. 进程不是本项目的 Python 工作台：不终止未知进程，删除失效的本项目 PID 记录后启动新实例。
2. 缺少、损坏或 PID 不匹配的启动元数据：将现有本项目工作台视为旧版本，安全停止后重启。
3. 元数据模式与本次请求不一致：停止并重启。
4. 元数据 Git 提交号或生产源码内容指纹与当前值不一致：停止并重启。
5. 模式、提交号与内容指纹均一致：复用现有进程，只打开两个页面。

停止脚本同时删除 PID 文件和启动元数据。若 Git 提交号不可读取，启动器使用稳定的 `unknown` 值；内容指纹仍可识别未提交代码变化。指纹只覆盖运行所需的 Python 与 PowerShell 源码，不读取 `.env`、运行数据、日志或账户导出文件。

### 收盘状态

调度器识别 `CLOSED` 时继续禁止实时行情请求，并向工作台发布明确的 `MARKET_CLOSED` 原因。中文页面显示“市场已收盘”；没有可信缓存时价格保持空白，有缓存时只能标记为过期数据，绝不升级为“良好”或“就绪”。

### 页面行为

启动脚本仍自动打开：

- `http://127.0.0.1:8765/`
- `http://127.0.0.1:8765/advisory`

重新启动后页面加载当前代码；复用时不会产生第二个后台服务。浏览器缓存仍可通过普通刷新更新，服务器端不再保留旧版内存代码。

## 错误处理

- 运行元数据无法解析时失败关闭到“重启本项目工作台”，不复用状态不明的进程。
- 不根据 PID 直接终止进程；必须先验证该进程命令行属于本仓库的 `quant_cli.py workbench`。
- 启动失败时保留日志并返回非零状态，不写入表示成功的元数据。
- 收盘状态与数据源请求失败分开显示，便于用户判断是否需要排查网络。

## 测试与验收

1. 先增加启动器回归测试，证明旧实现会错误复用离线或旧版本进程。
2. 覆盖：模式一致复用、模式不一致重启、提交号不一致重启、源码指纹不一致重启、元数据损坏重启、未知 PID 不被终止、停止脚本清理元数据。
3. 增加工作台状态测试，证明 `CLOSED` 显示“市场已收盘”，且不会生成实时价格或良好质量状态。
4. 运行启动器、工作台、实时调度相关测试以及全量 `pytest`、Ruff 和差异检查。
5. 本机验收：联网启动命令包含 `--network`；人工投顾页面包含三个导入按钮；收盘时状态明确；下一交易时段等待两次不同快照后再允许“良好”。

## 成功标准

- 用户双击桌面快捷方式后无需手工停止旧离线进程或修改网址。
- 代码更新后不会继续提供旧版页面。
- 收盘与离线故障在中文界面中可明确区分。
- 行情和交易安全门没有被放宽。
