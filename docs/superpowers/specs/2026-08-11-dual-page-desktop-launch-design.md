# 桌面快捷方式双页面启动设计

## 目标

双击现有桌面快捷方式 `A股量化交易系统.lnk` 后，在默认浏览器中同时打开：

1. `http://127.0.0.1:8765/`：官方日选与盘中监控。
2. `http://127.0.0.1:8765/advisory`：本地人工投顾与成交登记。

不新增第二个桌面快捷方式，不改变本地回环地址、端口、纸面模式或人工执行边界。

## 启动行为

- 现有快捷方式继续调用 `scripts/start_quant_workbench.ps1`。
- 服务尚未运行时，启动器先创建后台进程并等待健康接口返回成功，再按固定顺序打开主监控页和人工投顾页。
- 服务已经运行时，启动器不重复创建进程，直接按相同顺序打开两个页面。
- 页面通过 Windows 默认浏览器打开；现代浏览器通常会在同一窗口建立两个标签页。具体窗口归组由用户的默认浏览器策略决定，启动器不使用浏览器专属参数。

## 安全与错误处理

- 只打开固定的 `127.0.0.1` 地址，不接受外部 URL 或用户输入 URL。
- 如果新服务在有界等待时间内未通过健康检查，不打开页面，并保留现有错误日志提示。
- PID 文件仍只用于识别本项目启动的工作台进程，不终止或复用无关进程。
- 不增加自动下单、券商控制、键鼠自动化或外部网络权限。

## 测试

- 静态启动器回归要求脚本包含根路径 `/` 和 `/advisory` 两个固定 URL。
- 回归同时覆盖“已有进程”与“新启动成功”两个分支，确保两个分支都调用同一个双页面打开函数。
- 保留原有回环绑定、PID、隐藏窗口、参数转义和路径安全测试。
- 修改后运行启动器安全测试、工作台 HTTP 测试、Ruff 和 `git diff --check`。

## 验收标准

- 双击现有桌面快捷方式，无需手动修改地址即可看到两个页面。
- 桌面只保留现有的 `A股量化交易系统.lnk`。
- 两个页面均来自同一工作台进程和同一端口，且仍为简体中文、纸面监控、人工执行模式。
