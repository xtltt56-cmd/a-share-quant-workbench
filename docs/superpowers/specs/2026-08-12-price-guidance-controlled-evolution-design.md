# A股价格指导与受控进化系统设计

**日期：** 2026-08-12  
**状态：** 已确认，待实施计划  
**适用范围：** 官方日选、导入/登记持仓、本地人工投顾、研究训练与模型治理

## 1. 目标与边界

本升级为官方日选和已有持仓增加可解释、可审计的价格指导栏，并建立随真实结果积累而持续评估挑战者模型的受控进化机制。

系统回答两个相互独立的问题：

1. **预测层：** 一只股票未来 5、10、20 个交易日获得成本后超额收益的概率和分布是否足以支持继续研究或建立仓位。
2. **执行层：** 在预测层允许的前提下，什么价格区间、风险边界和仓位规模才可接受。

执行层不能替代预测层，复杂预测模型也不能绕过执行与组合风险门。系统保持人工执行，不新增自动下单、撤单、券商凭证读取或交易指令提交能力。

本功能不能承诺收益、固定胜率或持续提高准确率。“进化”只表示新模型可自动训练和接受样本外评估；正式模型的晋升必须由用户人工批准。

## 2. 用户可见结果

### 2.1 官方日选价格指导

官方日选表格增加以下字段：

- 证券名称和代码；
- 日选分数与排名；
- 最新有效价格；
- 研究级观察价；
- 建议买入区间；
- 最高可接受价；
- 信号失效价；
- 建议数量；
- 5/10/20 日预测周期；
- 成本后超额收益概率及校准状态；
- 数据截止时间与适用交易日；
- 指导等级和中文原因。

### 2.2 持仓价格指导

本机账本和已确认券商快照中的持仓显示：

- 成本价、当前价和浮动盈亏；
- 保护价；
- 持有观察区间；
- 减仓观察区间；
- 总数量、可卖数量和 T+1 状态；
- 模型优势变化；
- 指导状态、原因、数据截止时间和撤销条件。

成本价只参与盈亏与账户风险计算，不作为机械止损线。系统不显示“必涨价”“保证盈利价”或未经校准的单点目标价。

### 2.3 指导等级

| 等级 | 页面含义 | 是否显示价格 | 建议数量 |
|---|---|---:|---:|
| `RESEARCH_REFERENCE` | 研究参考，模型尚未通过晋升门 | 显示研究区间和风险边界 | 固定为 0 |
| `CONDITIONS_MET` | 冠军模型、数据、执行与风险门全部通过 | 显示条件性价格计划 | 按风险预算计算 |
| `WAIT_FOR_PRICE` | 标的合格，但当前价尚未进入区间 | 显示基础区间 | 0 |
| `PRICE_TOO_HIGH` | 当前价超过最高可接受价 | 显示上限和原因 | 0 |
| `RISK_ALERT` | 持仓跌破保护价或组合风险超限 | 显示保护价；不伪造可成交价 | 仅显示可卖数量 |
| `NO_RELIABLE_GUIDANCE` | 数据、模型、交易状态或口径不合格 | 不显示可执行价格 | 0 |

红、橙、蓝、绿、灰只作辅助，所有状态必须同时提供简体中文文字和机器可读原因码。

## 3. 模块架构

### 3.1 数据与特征层

第一层立即使用：前复权日线、未复权实际价格、成交额、换手、波动率、指数/行业相对强弱、交易状态，以及人工登记或券商导入的持仓。

第二层在通过点时数据检查后启用：财务报表、估值、公告日期、财报修订、分红送转、停复牌、风险警示和历史指数成分。

第三层在获得正式授权后启用：QMT 实时行情、Level-2、逐笔数据和更高质量基本面数据。

每个数据集必须记录来源、接收时间、交易所时间、复权方式、数据版本、覆盖率与质量状态。新增数据源只有在走步验证中证明独立增量价值后才能进入正式模型。新闻、政策和情绪特征在时间戳、历史复现、版权与未来信息泄漏审计通过前，只能进入实验池。

### 3.2 预测层

预测目标不是“明天是否上涨”，而是：未来 5、10、20 个交易日中，相对基准的收益能否在扣除佣金、印花税、滑点和不可成交约束后超过最低有效收益门槛。默认基准固定为沪深 300；只有证券具备点时行业分类和可复现的点时行业指数时，才使用同一交易日的行业指数作为该证券基准。最低有效收益门槛固定为“完整往返成本估计 + 0.50%”，两部分均以收益率表示并写入预测标签版本。

模型序列：

- 线性/逻辑回归：不可省略的简单基准；
- LightGBM：首个机器学习冠军候选；
- Qlib DoubleEnsemble：主要挑战者；
- TFT 或其他深度时序模型：仅手工启动的实验挑战者。

输出包括横截面排名、成本后超额收益分布、上涨概率、预测不确定性和特征贡献。概率必须在独立时间段校准；样本较少时优先使用 sigmoid 校准，只有独立校准样本不少于 1,000 时才允许评估 isotonic 校准。价格/收益区间第一版使用按预测周期分别维护的滚动绝对残差分位数进行保序共形校准：校准窗口为最近 252 个已到期交易日样本，目标覆盖率为 80%，最少需要 500 个已到期股票—周期样本；不足时区间状态为 `UNCALIBRATED`。自适应共形只能作为挑战者，必须通过相同走步窗口和覆盖率门后才能替换第一版校准器。

### 3.3 价格执行层

价格执行层是独立、确定性且版本化的模块。它读取已冻结的日线特征、预测结论和市场规则，生成次一交易日基础计划。盘中只更新计划状态，不能重新抬高买入区间。

### 3.4 账户风险层

默认保守参数：

- 单只股票市值不超过账户权益的 5%；
- 单一行业合计不超过账户权益的 20%；
- 单笔计划风险不超过账户权益的 0.5%；
- 买入数量按 100 股整手向下取整；
- 不足 100 股时不建议建立仓位；
- 持仓保护价只能保持或上移；
- 卖出受可卖数量和 T+1 约束。

所有参数进入版本化配置，不允许在线模型直接修改。

### 3.5 服务、页面与审计层

服务端生成结构化价格计划，浏览器只展示，不计算金融指标。每份计划和每次状态变更保存数据版本、模型版本、参数版本、计算时间、证据截止时间、输入摘要和原因码，以便复现。

## 4. 价格数据口径

技术指标使用前复权日线。页面价格统一换算为当前未复权实际交易价格：

```text
actual_factor = latest_raw_close / latest_forward_adjusted_close
actual_guidance_price = adjusted_guidance_price * actual_factor
```

账户成本价始终使用券商或人工成交的真实口径，不复权。发生除权除息、复权因子改变或代码状态改变后，旧计划立即失效并要求重算。

普通 A 股价格按证券适用的最小报价单位和当日价格限制取整。系统不得把默认 10% 涨跌幅套用于创业板、科创板、北交所、风险警示、新股上市初期或退市整理等特殊情形；在正式建立对应规则表前，这些证券统一返回 `UNSUPPORTED_SECURITY_RULES`，不生成可执行指导。

## 5. 第一版可解释价格公式

### 5.1 冻结输入

以最近一个完整交易日为 `D`：

- `C`：D 日前复权收盘价；
- `ATR14`：截至 D 的 14 日 Wilder ATR；
- `MA20`、`MA60`：截至 D 的 20/60 日前复权收盘均线；
- `S20`：截至 D 的最近 20 日前复权最低价；
- `A20`：截至 D 的 20 日平均成交额。

所有滚动指标只使用 D 及以前数据。日线少于 252 个交易日、`ATR14 <= 0`、`A20` 不达流动性门、数据含未来时间或缺失关键字段时不生成计划。

### 5.2 日选研究区间

```text
entry_anchor = min(C, MA20 + 0.50 * ATR14)
entry_lower_raw = entry_anchor - 0.50 * ATR14
entry_upper_raw = entry_anchor + 0.25 * ATR14
maximum_price_raw = min(entry_upper_raw, C * 1.01)
invalidation_raw = max(
    S20 - 0.25 * ATR14,
    MA60 - 0.50 * ATR14,
    C - 2.00 * ATR14,
)
```

约束：

- 若 `entry_lower_raw <= 0`，计划无效；
- 若 `entry_lower_raw > maximum_price_raw`，计划无效；
- 若 `invalidation_raw >= entry_lower_raw`，风险距离不足，计划无效；
- 若 `(entry_anchor - invalidation_raw) / entry_anchor` 超出配置的风险距离 `[2%, 12%]`，计划无效；
- 换算到实际价格后，买入下限向上取至最小报价单位，买入上限和最高可接受价向下取整，失效价向上取整；
- 舍入后区间为空或失效价不低于买入下限时，计划无效。

这组公式是版本 `price-guidance-rule-v1` 的研究执行基线，不代表收益预测。它只能在预测与风险门允许后升级为条件性建议。

### 5.3 建议数量

条件满足时，以不高于最高可接受价的计划价格 `P` 计算：

```text
risk_budget = equity * 0.005
position_budget = equity * 0.05
quantity_by_risk = floor(risk_budget / (P - invalidation_price))
quantity_by_weight = floor(position_budget / P)
raw_quantity = min(quantity_by_risk, quantity_by_weight)
suggested_quantity = floor(raw_quantity / 100) * 100
```

行业上限、现有持仓、可用现金、费用和滑点会进一步降低数量。研究参考、等待价格、价格过高和不可靠状态的数量均为 0。

### 5.4 持仓保护与减仓观察区间

```text
structural_protection = max(
    S20 - 0.25 * ATR14,
    MA60 - 0.50 * ATR14,
    C - 2.00 * ATR14,
)
protection_price = max(previous_protection_price, structural_protection)
reduce_lower = MA20 + 2.00 * ATR14
reduce_upper = MA20 + 3.00 * ATR14
```

首次生成时 `previous_protection_price` 为空，取 `structural_protection`。后续保护价只可上移或保持；除权除息时应先按复权因子等价换算旧保护价，再应用单调约束。保护价高于或等于当前价时保留该保护价并标记 `PROTECTION_BREACHED`，不能为美化状态而向下放宽。

进入减仓区间本身不产生卖出结论。还必须至少满足以下一项：模型成本后优势下降到阈值以下、趋势/波动率过热门触发、行业或组合风险超限。卖出指导数量不得超过券商快照或账本确认的可卖数量；当日买入不可卖时显示 `T_PLUS_ONE_BLOCKED`。

## 6. 盘中状态机

基础计划在 D 日收盘后生成，只对下一个适用交易日有效。盘中状态按最新 `GOOD` 行情更新：

```text
不可交易/数据非GOOD/计划过期 -> NO_RELIABLE_GUIDANCE
current_price > maximum_price -> PRICE_TOO_HIGH
current_price < invalidation_price -> INVALIDATED 或 RISK_ALERT
current_price 在买入区间内 -> RESEARCH_REFERENCE 或 CONDITIONS_MET
其他价格 -> WAIT_FOR_PRICE
```

盘中不得修改基础区间、最大可接受价或失效价。异常跳空、停牌、涨跌停、未来时间戳、行情倒退、数据过期和重大事件风险会撤销可执行状态。收盘或非交易时段可以展示最近计划供审计，但必须标记为过期/非实时。

## 7. 受控进化与模型治理

### 7.1 数据反馈闭环

每次预测写入不可变记录；到 5、10、20 个交易日到期后登记实际价格、基准收益、成本后超额收益、可成交性和区间覆盖结果。任何修订都追加新版本，不覆盖原始预测。

### 7.2 运行节奏

- 每次打开工作台：执行轻量增量更新、到期结果登记和待办检查；
- 每周：计算漂移、Rank IC、Brier 分数、校准误差、区间覆盖率和风险表现；
- 每月第一个周末且新增成熟样本达到配置门槛：训练 LightGBM 与 DoubleEnsemble 挑战者；
- 深度模型：仅人工启动实验；
- 工作台关闭时保存检查点并停止训练，不在系统关闭后常驻。

### 7.3 冠军—挑战者晋升门

挑战者必须同时满足：

- 影子运行至少 60 个交易日；市场状态覆盖不足时自动延长；
- 至少 1,000 个已到期的股票—周期预测样本；
- 通过至少 3 个连续、不重叠的样本外窗口；
- 5/10/20 日中至少两个周期的 Rank IC 优于冠军，且提升不由少数证券独占；
- Brier 分数和校准误差不劣于冠军；
- 计入费用、滑点、涨跌停、停牌和容量后，风险调整表现优于冠军；
- 最大回撤、换手率、行业暴露和流动性容量不违反阈值；
- Deflated Sharpe 与 PBO 检查不显示不可接受的多重试验/过拟合风险；
- 上涨、下跌、震荡和高波动状态中没有不可接受的单一状态崩溃；
- 无未来函数、数据泄漏、复现失败、特征漂移超限或区间失准。

达标只产生 `AWAITING_MANUAL_APPROVAL` 状态和中文比较报告。用户必须在本地页面明确批准才能晋升。审批记录包含旧/新模型摘要、评估报告哈希、操作者确认时间和回滚点。

正式模型漂移或校准失效时自动降级到 `RESEARCH_REFERENCE` 或 `NO_RELIABLE_GUIDANCE`，但不得擅自把挑战者晋升为冠军。旧冠军和配置保留，可审计回滚。

## 8. 运行生命周期

系统不创建开机自启动项或 Windows 计划任务。

桌面入口启动工作台后，由工作台监督一个研究任务子进程。训练使用 CPU、内存、最长运行时间和并发限制，并定期原子保存检查点。训练故障不得中断现有冠军和页面服务。

关闭单个浏览器标签页不代表退出系统。两个页面右上角提供“安全退出系统”按钮，桌面另保留停止入口。安全退出顺序为：停止接收新研究任务、请求保存检查点、停止数据更新和行情轮询、在限定时间内结束研究子进程、记录退出结果、最后停止工作台。下次打开时只从校验通过的检查点恢复。

退出后不得保留训练、行情轮询或量化服务进程。强制中断后，下次启动必须检查孤儿进程、未完成检查点和状态日志，失败时保持降级状态。

## 9. 持久化契约

建议新增以下版本化对象：

- `PriceGuidancePlan`：标的、计划类型、指导等级、价格区间、保护/失效价、数量、有效期、特征摘要、模型/配置/数据版本和原因码；
- `PriceGuidanceObservation`：盘中价格、行情质量、状态变化、接收时间和计划引用；
- `MaturedForecastOutcome`：预测周期、实际收益、基准收益、成本后超额收益和可成交性；
- `ModelEvaluationReport`：窗口、指标、市场状态切片、试验计数、晋升门结果和制品哈希；
- `ModelPromotionRecord`：人工批准/拒绝、旧冠军、新冠军和回滚信息；
- `ResearchJobState`：任务类型、检查点、资源限制、进度、停止原因和恢复资格。

文件写入沿用项目现有的同目录临时文件、刷新落盘、原子替换、摘要校验和边界路径验证。账户数据、环境变量、令牌和券商身份不得写入模型制品或页面 API。

## 10. 页面设计

主工作台的官方日选表格采用“摘要列 + 点击展开详情”：摘要显示当前价、买入区间、最高价、失效价、有效期与状态；详情显示 ATR、均线、支撑位、预测周期、校准状态、仓位上限、原因和撤销条件。

人工投顾的持仓区改为结构化表格：成本价、当前价、盈亏、保护价、减仓区间、可卖数量与状态；详情展示 T+1、数据来源、风险预算和模型优势变化。

页面不在 JavaScript 中计算价格。API 的 `null` 价格必须显示“暂无可靠指导价”，不得显示 0 或空字符串。研究参考始终显示醒目标识：“尚未通过模型晋升门槛，不构成买入或卖出建议”。

## 11. 失败关闭规则

以下任一条件使可执行指导失败关闭：

- 实时行情质量不是 `GOOD`；
- 有效日线不足 252 日；
- 时间倒退、未来数据、关键字段缺失或来源不明；
- 除权除息后计划未重算；
- 停牌、风险警示或证券规则尚不受支持；
- 概率未独立校准、预测区间过宽或模型漂移超限；
- 股票流动性不足、跳空超过最高价或触及交易约束；
- 账户权益、现金、持仓或可卖数量过期，无法可靠计算风险；
- 模型/配置/数据制品摘要不匹配；
- 研究任务、检查点或模型晋升状态不完整。

失败时保留审计证据，页面显示具体中文原因。系统不能用历史缓存把状态升级成 `GOOD` 或 `CONDITIONS_MET`。

## 12. 测试与验收

实施必须采用测试驱动开发，并覆盖：

1. 指标只使用过去数据，复权/未复权换算正确；
2. 每个公式、报价单位方向性舍入和无效区间拒绝；
3. 研究级建议数量永远为 0；
4. 条件满足数量同时受风险、仓位、行业、现金和整手限制；
5. 盘中上涨不会抬高冻结区间；
6. 计划过期、数据降级、跳空、停牌、涨跌停和除权失效；
7. 保护价在相同复权口径下不下降；
8. T+1 与可卖数量限制；

## 14. 研究依据

- Microsoft Qlib 提供面向量化研究的模型与实验基础；DoubleEnsemble针对金融数据低信噪、非平稳和复杂模型过拟合问题使用样本重加权与特征选择：<https://arxiv.org/abs/2010.01265>
- LightGBM 是适合表格因子和较低本地训练成本的梯度提升基线：<https://proceedings.neurips.cc/paper_files/paper/2017/hash/6449f44a102fde848669bdd9eb6b76fa-Abstract.html>
- 概率校准必须使用独立于模型训练的数据；isotonic 在样本较少时更易过拟合：<https://scikit-learn.org/stable/modules/calibration.html>
- 时间序列共形方法为多周期预测提供误差区间与覆盖率评估思路：<https://proceedings.neurips.cc/paper_files/paper/2021/hash/312f1ba2a72318edaaa995a67835fad5-Abstract.html>
- Deflated Sharpe 用于纠正多次试验、选择偏差与非正态带来的虚高表现：<https://www.davidhbailey.com/dhbpapers/deflated-sharpe.pdf>
- 上交所现行交易规则用于约束报价单位、申报范围和价格限制；不同板块与特殊证券必须采用适用规则而非统一假设：<https://www.sse.com.cn/lawandrules/sselawsrules2025/stocks/exchange/c/c_20260424_10816482.shtml>
