# 前端 V2 升级方案

## 目标与范围

按已确认的专业终端方向升级全部六页：石墨灰画布、克制蓝色、精确数字排版，简体中文优先；减少重复说明，突出价格指导、行情时效与待处理事项。继续使用现有 Python + HTML/CSS/JavaScript 和本地 ECharts，不新增运行依赖。

本次完成本地实现及验收。保持桌面入口、API、经典页面、模型和账户存储兼容。发布操作按独立的 GitHub 发布流程执行。

## 视觉与文案规范

- 默认深色（尊重已保存的主题选择），完整浅色主题；背景石墨灰，导航略深，内容面板仅轻微层差。
- 导航使用统一线性 SVG；6–8px 圆角、细横分隔线、少阴影。避免营销横幅、重复卡片、装饰图表。
- 中文正文 13–14px，标题 24–28px，数字等宽并对齐；辅助文字原则上不少于 12px。
- 首屏只保留页面名、数据日期、实际状态和刷新操作。删除英文眉题和口号。
- 交易日期、数据过期、账户账本/券商快照区别直接可见；计算解释、流程限制与字段说明放可展开详情。
- 不把候选分数表示成上涨概率；没有风险等级、市场宽度、模型成绩的真实字段就不生成对应图形或数值。

## 六页设计

1. 投资总览：紧凑状态带；主要区域为前五名日选及价格区间；右侧只显示真实待处理事项并链接对应页面；下方显示数据时效和实际模型记录摘要。
2. 日选研究：搜索、排序、已有价格区间筛选；股票/代码、分数、参考区间、指导状态、信号日期；缺失原因可展开。没有指导价时不填零。
3. 盘中监控：搜索及日选/持仓/自选筛选；股票名在代码前；最新价、涨跌幅、状态、价格区间、时间、质量。桌面保留完整列，窄屏变成带字段名的紧凑列表。
4. 我的持仓：账本摘要、持仓及价格计划、成本分布、独立券商快照；登记和导入并列工作区，保留四项简单登记、预览确认和文件扫描流程。
5. 模型观察：实际冠军、治理和记录状态；预测对证流程压缩为辅助说明，不生成虚构成绩或成熟样本数。
6. 数据与系统：数据源、更新时间、年龄、延迟、故障和安全退出；详细操作说明折叠。

## 个股详情

- 顶部股票名/代码、自选操作及行情摘要；价格指导先于 K 线。
- 有效数值显示参考区间、最高可接受价、失效价和适用日期；无效或缺失显示具体中文原因。
- 价格轴只对符合数值边界的计划显示；有效行情才显示当前价定位。
- K 线使用实际本地日线，参考区间与价格线仅在价格口径和适用时间能够确认时叠加，无法确认则保留独立价格轴。
- 候选理由和策略版本放辅助区域，保持可查。

## 实施顺序与恢复

1. 检查现有页面、接口与 Git；生成并保存精修概念图。
2. 修改页面骨架与全局设计变量、图标、深浅主题和响应式样式。
3. 调整实际数据呈现、错误提示、价格详情和持仓区域；保持已有接口请求。
4. 真实浏览器逐页验证并修正；运行相关后端回归及 JS 语法检查。
5. 更新交接报告，记录概念偏差、验收结果及限制。

代码通过 Git 差异恢复；不删除用户数据、不重置浏览器的主题和自选偏好，不为展示新增虚假成交。

## 验收标准

- 六页均能访问，主题、导航折叠、紧凑模式、自选、搜索、排序和过滤有效。
- 1440×1000、1366×768 和 390×844 视口：没有页面级横向溢出、字段截断或主操作遮挡；窄屏表格可直接读取关键字段。
- 价格缺失、行情过期、连接失败都有真实且简短提示；缺失值不显示为 0，不因连接断开保留“正常”外观。
- 本机持仓与券商快照保持独立；修改登记或导入选择后废弃预览确认令牌。
- K 线与成交量可加载、缩放，详情关闭/打开不会串股票；键盘焦点和 Esc 正常。
- 相关前端/服务/启动/账户测试通过；浏览器无应用控制台错误。
- 检查概念与实际截图的布局、字体、颜色、间距、图标、文案六方面。差异如为数据真实性或可访问性必须记录原因。
