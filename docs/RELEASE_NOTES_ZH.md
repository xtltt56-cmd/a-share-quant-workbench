# A股量化交易工作台公开预览版

本版本由 GitHub 在干净的 Windows 环境完成测试和构建。版本号、Git 提交和构建时间记录在发布包内的 `VERSION.json`。

## 0.2.4 AI 联网研究与工作流可靠性升级

- 新增独立「AI 分析」页面，支持证券代码添加、筛选、批量选择、逐只执行和停止本批分析。
- 分开展示原工作流事实、Agent 补充判断、证据观察、待验证推断、网络来源和费用估算。
- 支持 DeepSeek 官方云端接口及可选本地 Ollama；默认关闭，不自动调用收费模型或下载模型。
- 新增网页 API 密钥配置入口；使用 Windows 当前用户 DPAPI 加密保存，状态接口不返回密钥。
- 增加有界公开网页检索与正文节选读取，区分标题、摘要、正文、读取失败及日期未知，拒绝私网地址。
- 联网研究结合既有历史指标和公告线索，不以媒体观点代替原始披露，不编造指导价或收益概率。
- 修复短历史样本回撤计算的边界问题，以及公告核验否定句被误判为肯定断言的问题。
- 完善日线刷新、阶段恢复、数据时间校验、行情进程隔离及原子持久化；失败不伪装成成功。
- 发布包包含受约束的 Agent SDK，不包含 API 凭据、账户数据、本机实验报告或运行缓存。
- 云端链路已完成小样本真实调用和页面验收；本地模型质量、广泛市场适用性和预测效果仍需独立验证。

## 0.2.3 官方公告风险检查

- 新增无需账号的巨潮资讯公告风险层，覆盖当前日选候选和已登记持仓。
- 重大公告、需要复核的公告、检查失败或尚未覆盖时，系统会暂停相关股票的价格指导，避免把信息缺失误判为安全。
- 公告检查在独立低频线程运行，新一批日选生成后会立即唤醒检查，不阻塞盘中行情更新。
- 公告快照存放在 D 盘项目目录，采用容量限制、严格校验和原子替换；系统只保存公告元数据，不下载 PDF 正文。
- 日选、盘中监控、持仓、个股详情和系统健康页均可查看公告风险状态与官方原文链接。
- 统一项目包版本号，修复程序自报版本与发布包版本不一致的问题。

## 0.2.2 前瞻评估可靠性修复

- 模型包升级时自动归档旧竞赛并启动新竞赛，旧预测仍可继续结算，不再因版本切换永久卡住。
- 结算器优先使用小型、带 SHA-256 校验的规范日线文件，缺失时才回退到研究快照，显著缩短启动结算时间。
- 每个模型版本独立计算成熟数量、覆盖率和收益指标，避免旧版与新版结果混算。
- 同一份日选信号使用稳定周期标识，工作台或研究任务重启不会重复登记预测。
- BaoStock 日线保留交易所涨跌幅，并在结算时核对五个交易日复合收益；发现除权除息冲突或证据不完整时停止计分。
- 规则模型使用明确的“无拟合训练状态”快照，不再因无关历史数据清单变化而反复重置前瞻竞赛。

## 主要内容

- 简体中文专业工作台：投资总览、日线候选、盘中监控、持仓、个股详情和价格指导。
- 新增无需账号的巨潮资讯公告风险层：覆盖当前候选和持仓，展示官方公告链接，并在重大事件、检查失败或尚未覆盖时暂停价格指导。
- 公告抓取在独立低频线程运行；新一批日选生成后立即唤醒检查，不阻塞盘中行情轮询。
- 公告快照采用有界、严格校验和原子替换；缓存损坏时工作台继续启动，但在重新取得有效快照前保持风险关闭状态。
- 本地人工投顾与财信证券官方导出文件的预览、确认导入流程。
- 数据新鲜度、来源、质量和降级状态明确展示，不以缓存冒充实时行情。
- 模型前瞻验证进度和只读研究汇总。
- 项目内存储边界、受控研究生命周期和人工执行安全限制。
- Windows 在线安装包和自带运行环境的便携包。

## 下载选择

- `Online.zip`：首次运行联网安装 Python 官方运行时和受约束依赖。
- `Portable.zip`：已经包含运行时，完整解压后可直接启动。
- `SHA256SUMS.txt`：两个发布包的完整性校验值。

## 重要限制

- 本版本是人工决策辅助和纸面观察工具，不包含自动下单。
- 免费公开数据源不提供交易级可用性承诺。
- 公告风险目前依据标题规则筛查，不能替代阅读公告正文、监管文件或专业合规判断。
- 模型仍需持续积累未来真实结果，不承诺预测准确率或收益。
- 可选 Token、券商权限和个人账户数据不会包含在发布包中。
