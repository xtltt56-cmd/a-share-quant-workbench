# 前端 V2 交接说明

后续升级及修正见 `FRONTEND_V21_HANDOFF.md`；以下保留 V2 当时的记录。

## 完成结果

前端已从“说明型卡片页面”升级为兼顾信息密度与直观性的专业工作台。保留原有本地服务、接口、账户数据、桌面入口和经典页面，不新增运行依赖，也没有生成任何虚假行情、模型成绩或成交记录。

主要变化：

- 默认专业深色主题，同时保留浅色主题、紧凑模式和可折叠导航。
- 首页改为状态带、日选主表、待处理、风险提示、数据时效和模型记录，首屏直接回答“数据是否可用、有哪些候选、是否有价格区间”。
- 日选和盘中监控统一显示股票名称、代码、价格计划、行情时间与质量；手机端表格转换为带字段名的列表，不再依赖横向滚动。
- 股票详情先显示价格指导，再显示真实本地 K 线、成交量、候选依据和策略版本。
- 持仓页保留四项简单人工登记，以及券商导出文件的扫描、预览、确认导入流程。
- 所有导航和操作图标改为本地内嵌 SVG；状态色统一为蓝、绿、黄、红四类语义色。
- 价格缺失、行情过期、非交易时段、接口异常均显示真实状态；候选分数明确作为排序分数，不冒充上涨概率。

## 当前真实状态与限制

- 验收时接口返回 10 只日选、48 只盘中监控；其中 7 只有价格区间。
- 行情状态为“过期 / 非交易日”，48 条盘中报价均被正确标记为过期。页面不会把这些数据伪装成实时可交易信号。
- 日线截止日期为 2026-09-11；系统记录的行情最后更新时间较早，因此投资总览和风险区持续提示核验。
- 当前模型接口没有提供可比较的未来对证成绩，模型页如实显示“接口尚未提供”，没有伪造胜率或收益曲线。
- Figma 文件已创建，但 Starter 套餐的 MCP 调用额度已耗尽，画布暂为空白：`https://www.figma.com/design/eV9X8p4E5spKyQei6NRDyT`。本地实现不依赖 Figma；额度恢复后可再把已验收页面同步为可编辑组件。
