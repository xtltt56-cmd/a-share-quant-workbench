## 一、当前可用结论

当前版本已经可以启动本地工作台，并且“官方日线候选”和“盘中监控”不会因为实时源暂时不可用而空白：

- 官方日选：已从本地真实 BaoStock 日线生成 10 条候选，信号日期为 2026-08-10。
- 盘中监控：启动时先展示这 10 条候选的 `STALE_DATA` 监控行；实时行情通过质量核验后才覆盖价格和状态。
- 当前现场验收：`AKShare / Sina` 返回 100 条展示行情和 100 条监控行；由于免费全市场快照含局部旧时间戳，质量会显示“降级”，监控保持 `STALE_DATA`，不会伪造 `READY`。
- 人工投顾页：支持持仓回放、人工成交四字段登记（名称、代码、数量、价格）、预览/确认两步记录。
- 自动交易：没有委托、撤单或自动报单路径；所有建议都标记为仅供人工执行。
- 当前日选是固定权重横截面“排名”，不是经过样本外校准的收益概率预测。因此没有把排名伪装成“买入/卖出”结论；没有经核验上下文时，人工投顾页明确显示“暂不操作”。

## 二、已完成的主要工作

### 数据与日选

1. 增加 BaoStock 历史日线适配器和 CSI300（`000300` → `sh.000300`）指数读取。
2. 生产日选只接收来源为 `baostock` 的规范化日线，拒绝 fixture、回放、合成和测试数据。
3. 生产门槛固定为：单标的至少 252 个交易日、共同日期横截面至少 30 只股票、20 日平均成交额至少 1000 万元、收盘价高于 60 日均线。
4. 使用现有规则因子引擎，不另造未经验证的模型；估值因子在免费数据阶段禁用，避免把价格倒数误当估值。
5. 生成结果以原子方式写入 `.runtime/signals/official-daily.json`，含数据截止日、模型/特征版本、排名理由、参考价格和失效价格。

### 实时行情与质量控制

1. 免费实时端点顺序为新浪 → 东方财富 → 腾讯；当前新浪成功时显示 `AKShare / 新浪`。
2. 全市场请求最小间隔 60 秒，并对失败端点做 300 秒冷却，避免 AKShare 高频调用触发临时封禁。
3. 腾讯备援已修正成交量（手→股）和成交额（万元→元）单位；因为缺少可靠交易所时间，腾讯只标记为降级数据，不能进入 GOOD。
4. 未来时间戳、过期报价、缺失标的和倒退时间戳均会被隔离；质量门只有连续两个不同且新鲜的快照才可进入 GOOD。
5. 全市场快照中单个代码的倒退时间戳只隔离该代码；其余行情继续进入降级监控，避免单行异常使整批行情消失。服务层取调度器与质量门的较差状态，严禁把降级快照升级为 `READY`。
6. 实时源不可用、闭市或刚启动时，系统保留日选对应的监控行并标记 `STALE_DATA`，严禁生成可执行结论。

### 本地人工投顾与账本

- `GET /` 和 `GET /advisory` 均为简体中文页面；浏览器若仍显示旧英文内容，请强制刷新（Ctrl+F5）。
- 持仓来自本机 JSONL 账本回放，不冒充券商持仓。
- 人工登记只需名称、代码、数量、价格；预览不会落盘，确认后才追加账本。
- 确认令牌一次性消费，重复确认被拒绝。
- 指导建议会显示证据截止日、状态、理由和人工执行提示；没有正式预测上下文时返回 `暂不操作`。

## 四、财信证券连接状态与必须的人工步骤

当前登录的“财信证券专业版”是普通同花顺组件，不是迅投 QMT；本机没有 `xtquant`、`userdata_mini` 或 QMT Python 组件。因此不能也不应通过界面抓取、OCR 或逆向方式读取账户数据。

财信官网将“财信证券专业版”和“迅投 QMT”列为两个独立软件。要使用官方只读行情/资产接口，仍需由用户完成：

1. 联系 95317 或客户经理，申请开通“迅投 QMT 量化服务和 XtQuant Python API 权限”，明确只申请行情、资产、持仓查询，不使用程序化报单。
2. 确认系统费、资产/交易量门槛，以及是否包含 Level-1 实时和历史行情；不能仅凭软件下载页推断免费无门槛。
3. 审批后从财信官方软件下载页安装迅投 QMT，登录 MiniQMT，并确认外部 Python 能找到 `xtquant` 与 `userdata_mini`。

完成上述人工步骤后，后续只实现只读桥接：SDK 路径发现、健康检查、行情适配、资产/持仓查询和失败降级；永久不暴露下单/撤单接口。

## 六、尚未完成或需要后续迭代的事项

1. **官方 QMT 只读连接**：等待财信审批和用户安装/登录 QMT；普通客户端登录不能替代该权限。
2. **可校准预测**：目前只有规则排序，没有样本外收益概率、置信区间或经过走步验证的 LightGBM/双重集成冠军模型，不能承诺准确率。
3. **基本面与 PIT 数据**：免费阶段尚未建立完整公告日、财报修订和历史成分股 PIT 数据，估值/质量因子暂不启用。
4. **跨进程实时快照缓存**：当前有同进程节流和日选降级展示；重启后实时快照仍需重新核验，后续应加入带摘要校验的原子缓存，并始终标记 `CACHED/STALE`。
5. **实时调度运营**：目前工作台后台轮询已具备，但还没有生产级任务编排、告警、轮换日志和长期监控面板。
6. **交易成本与回测**：应在扩大股票池后加入滑点、印花税、佣金、涨跌停、停牌和 T+1 约束，并执行严格的时间切分/样本外回测。

这些项目完成前，系统适合作为“研究辅助 + 人工复核 + 纸面监控”，不应被描述为自动赚钱或准确预测系统。
