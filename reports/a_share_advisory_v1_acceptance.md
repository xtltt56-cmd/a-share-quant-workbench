# A 股人工投顾系统 V1 验收报告

生成时间：2026-08-10  
运行边界：Windows、本地回环地址、纸面/人工执行模式

## 验收结论

**本地人工投顾链路可验收；真实市场和券商权限仍是外部闸门。**

系统可以在本地保存人工成交、回放持仓、生成带证据截止时间的中文指导，
并对数据不足、风险阻断和 QMT 下单请求采取拒绝或暂停策略。系统没有自动
下单接口，也不会通过券商网页或非官方协议执行交易。

## 已完成的主要模块

- 账户账本：四字段人工登记（名称、代码、数量、价格）、A 股 100 股整手、T+1、费用、现金、成本和成交回放。
- 指导引擎：BUY/HOLD/WATCH/REDUCE/EXIT/BLOCKED/INSUFFICIENT_DATA 状态，数据质量、市场状态、事件风险、现金、集中度、流动性和回撤闸门。
- 预测证据：5/10/20 个交易日预测记录、不可变预测、到期结果追加、模型卡、挑战者和人工批准晋级边界。
- 数据溯源：来源、时间截点、规范化标识、哈希和来源切换闸门。
- 数据源：AKShare、BaoStock 日线适配器；Tushare 可选适配器；实时层仍按 RQData → Tushare → AKShare 的权限感知顺序工作。
- 中文工作台：本地回环 HTTP 界面、持仓、今日指引、模型/数据状态、人工成交预览/确认；根工作台和人工投顾页均为简体中文。
- 备份恢复：白名单清单、哈希校验、防目录穿越、可恢复日志、并发锁和审计记录。
- QMT 边界：只读能力检测、账户快照规范化、账本对账预览；所有 `submit_order` 入口永久拒绝。

## 数据源连接证据

### AKShare

已安装，默认不需要 Token。真实请求受上游接口和当前网络代理影响；失败时系统保留失败状态，不把异常当作交易信号。

### BaoStock

已安装 `baostock` 0.9.3，并加入 `data-free` 可选依赖和统一 `update_data.py` 命令。真实受控请求已经成功完成登录、股票池过滤、日线拉取和本地写入，最近一次最小验证写入 4 条日线记录。

验证命令：

```powershell
.\.venv\Scripts\python.exe scripts/update_data.py --provider baostock --start-date 2026-08-04 --end-date 2026-08-07 --limit 1 --network-smoke
```

### Tushare

Tushare 依赖已安装，Windows 用户级环境变量可被项目读取；本次最小请求明确返回账号没有 `stock_basic` 和 `daily` 接口权限。系统因此将 Tushare 保持为未授权可选源，不会伪造数据，也不会把权限错误写成预测结果。

要启用它，必须由账户持有人在 Tushare 后台取得相应接口权限；这是外部账号权限，代码无法替代。

## 端到端离线验收

`scripts/run_advisory_acceptance.py` 的确定性夹具验证了：

1. 没有调用方提供的市场上下文时，结果为 `INSUFFICIENT_DATA`，建议为“数据不足”；
2. 人工买入先预览，未确认前不写入账本；确认后持仓和现金可回放；
3. 带历史上下文的指导生成 `BUY_CANDIDATE`，同时保留 `manual_execution_required=true`；
4. 5 日预测到期后追加 1 条结果，不修改原预测；
5. QMT 只读快照与本地账本可以对账；
6. QMT 下单调用结果为 `REJECTED`。

运行命令：

```powershell
.\.venv\Scripts\python.exe scripts/run_advisory_acceptance.py
```

## 最终安全边界

- 默认 `paper`，`allow_live=false`；
- HTTP 只绑定 `127.0.0.1`；
- 不保存券商密码、Token 或 QMT 会话；
- 不导入或构造券商下单客户端；
- 人工登记字段固定为名称、代码、数量、价格；
- 数据不完整、过期、冲突或风险闸门失败时，系统应暂停或显示“数据不足”，而不是猜测。

## 尚未完成的外部闸门

这些不是可以靠继续写代码安全替代的事项：

在这些证据完成前，系统不能宣称预测准确、不能升级为实盘，也不能开放自动交易。
